# Button

Квадратная кнопка моноширинным капсом: `siren` - одно главное действие на экран, `outline` - всё остальное.

**Props:** `variant` (`siren` | `outline`), `href` (рендерит `<a>`), `arrow` (глиф после текста: `→`, `↓`, `↗`), `children`, любые атрибуты кнопки (`type`, `disabled`, `onClick`).

- `siren`: заливка `accent`, текст `on-accent` (5.3:1). На экране не больше одной - «Написать» в hero и «Отправить» в форме.
- `outline`: рамка `line-strong`, текст `ink`; на ховере инвертируется в `ink`/`surface`.
- Высота 48px, отступ 22px, `radius-none`. Фокус - кольцо `focus` 2px с отступом 3px.
- Не делайте кнопки со скруглением и градиентами; не ставьте две сирены рядом.
