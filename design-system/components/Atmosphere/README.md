# Atmosphere

Плёночный слой поверх страницы: анимированное зерно (SVG feTurbulence), едва заметные сканлайны и виньетка. `pointer-events: none`.

**Props:** `fixed` (по умолчанию `true` - на весь вьюпорт; `false` - внутри относительного блока), `grain`, `scanlines`, `vignette` (все `true`).

- Один экземпляр на страницу, последним в DOM.
- При `prefers-reduced-motion` зерно замирает; в лёгком режиме (тач, узкий экран, ≤4 ядер) второй слой зерна отключается.
- Фактуры миров - классы CSS, не компоненты: `aa-wallpaper` (обои), `aa-tiles` (кафель), `aa-metal` (рифлёный лист), `aa-grate` (решётка), `aa-slots` (перфорация), `aa-noise-fx` (пятна). Все нарисованы градиентами и SVG, без картинок.
