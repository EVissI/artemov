# Chip

Моноширинная метка-переключатель для фильтра работ по категориям.

**Props:** `active` (ставит `aria-pressed`), `count` (число, дополняется до двух цифр), `children`, `onClick`.

- Группа чипов оборачивается в `role="group"` с `aria-label`; первый чип - «Все».
- Активный - инверсия `ink`/`surface`; неактивный - рамка `line-strong`, `radius-xs`.
- Категории без работ не показывайте.
