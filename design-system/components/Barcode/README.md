# Barcode

Декоративный штрихкод, как на мерче: полосы детерминированно вычисляются из `seed`, так что у каждой работы свой, но стабильный рисунок.

**Props:** `seed` (обычно `id` работы), `bars` (число полос, 34), `className` (задайте размер: `aa-poster__code` 96×26, `aa-footer__barcode` 140×30).

- Цвет - `currentColor`, в Мире 2 это `ash`. Всегда `aria-hidden`: смысла не несёт.
