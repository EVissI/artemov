# Header

Фиксированный хедер: монограмма слева, меню моноширинным капсом по центру, «● REC» справа. На узком экране меню сворачивается в кнопку «Меню».

**Props:** `nav` (массив `{id, label}` из `content.nav`), `theme` (`fog` | `other` - тема секции под хедером), `active` (id текущего раздела → `aria-current`), `onNavigate(id)` (прокрутка; без него работают обычные якоря), `monogram`, `recLabel`, `fixed` (`false` - для превью).

- `Landing` сам определяет `theme` и `active` по секции под хедером.
- Фон - градиент от `surface` к прозрачному, без плашки и тени.
