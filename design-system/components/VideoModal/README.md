# VideoModal

Модальный плеер работы: YouTube-embed (через youtube-nocookie) или видеофайл, с заголовком, категорией, годом и описанием.

**Props:** `work`, `categoryLabel`, `onClose`.

- `videoUrl` - ссылка YouTube (watch, youtu.be, shorts, embed, live) или прямой файл (`.mp4`/`.webm`). Пусто - экран «Сигнал отсутствует».
- 9:16 открывается узкой колонкой, вписанной в высоту экрана.
- Esc и клик по фону закрывают; фокус уходит на «Закрыть», ходит по кругу внутри и возвращается на карточку после закрытия.
- Видео стартует только по клику пользователя - это и есть действие, автозвука на странице нет.
