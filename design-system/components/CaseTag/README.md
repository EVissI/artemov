# CaseTag

Кейс как бирка-протокол: плашка `ash` со срезанными углами и люверсом, «Протокол № 001», клиент, задача, что сделано, блок «Результат · было → стало» и ссылка «Смотреть →», в углу - печать-монограмма `rust`.

**Props:** `item` (`content.cases.items[]`: `id, client, task, done, metrics: [{label, before, after}], link, year`), `index`.

- Метрики - строки: «было» зачёркнуто и приглушено, «стало» крупно моноширинным. Для скринридера подписаны «было» и «стало».
- Нет ссылки - на её месте служебная метка слота.
- Бирки чередуют наклон −0.8° / +0.9°; в сетке `aa-cases__grid` колонки от 420px.
