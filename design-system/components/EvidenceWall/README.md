# EvidenceWall

Сцена первого экрана: стена следователя. Персиковые обои (`aa-wallpaper`), четыре приколотых кадра (16:9 и 9:16) с подписями-таймкодами, до трёх записок, плёнка, нити `rust` между булавками и большая процарапанная монограмма `stain`.

**Props:** `wall` (`content.hero.wall`: `frames` - `{image, caption}`, `notes` - строки), `works` (превью работ подставляются в пустые кадры), `monogram`.

- Заполняет родителя (`position: absolute; inset: 0`), рассчитана под `Hero` с фонариком поверх.
- Вся стена декоративная (`aria-hidden`): смысл страницы - в тексте hero.
- Кадры тонируются в ч/б с лёгкой сепией; пустой кадр - слот с водяной монограммой.
