# Tracklist

Список услуг как трек-лист с обратной стороны постера: римская нумерация, название `heading`, одна строка описания, таймкод.

**Props:** `items` - массив `{id, title, text, timecode?}` (`content.services.items`).

- Одна строка описания - не больше. Таймкод декоративный и на мобиле скрывается.
- Ховер и фокус: лёгкая статика (шум) по строке и два кадра глитча на названии со смещением `bloom`.
- В Мире 1 кладётся на фактуру `aa-tiles`; фон списка - полупрозрачный `surface-raised`, чтобы текст держал контраст.
