# PosterCard

Мини-постер работы в языке металкор-мерча: одна краска `ash` на `void`, рамка 1.5px, № и год римскими цифрами, маленькая монограмма, превью в рамке с уголками видоискателя, название `heading`, категория и формат, штрихкод, инверсная плашка «▶ Смотреть».

**Props:** `work` (элемент `content.works.items`: `id, title, category, format, year, previewImage, previewVideo, videoUrl, description, order, published`), `index` (номер на постере), `categoryLabel`, `onOpen(work)`.

- `format`: `16:9` или `9:16` - рамка превью берёт соответствующее соотношение, так что оба формата живут в одной колоночной сетке `aa-wall`.
- Превью: `previewImage` грузится лениво и тонируется в одну краску (ч/б + умножение на `ash`). `previewVideo` подгружается только при первом наведении и играет без звука. Без картинки - слот с водяной монограммой и подписью формата.
- Наведение и фокус: VHS-полоса, сканлайны, хроматический сдвиг, метка «● PLAY».
- Вся карточка кликабельна через одну кнопку с понятной подписью; открывает `VideoModal`.
