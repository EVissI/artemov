# Counter

Цифра-счётчик моноширинным шрифтом (`counter`), которая «набирается» при появлении в кадре: число растёт, неустоявшиеся разряды перебираются случайными цифрами.

**Props:** `value` (число или `null`), `display` (что показать при `value: null`, например `∞`), `suffix` (`+`, `млн`), `label`, `duration` (мс, 1400).

- Кладите в сетку `aa-counters` (2×2 с подписью `aa-counters__cap`).
- Скринридер слышит итоговое значение сразу; анимированный текст скрыт.
- При `prefers-reduced-motion` значение ставится без анимации.
