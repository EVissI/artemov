# Transmitter

Форма связи как радиопередатчик: дисплей с частотой и сигнальными полосами, «● ON AIR», заголовок «ПЕРЕДАТЬ СИГНАЛ», три канала-поля и кнопка-сирена «Отправить».

**Props:** `contact` (`content.contact`: тексты полей, кнопок, успеха и ошибки), `onSubmit(values)` → Promise, `initialState` (`idle` | `success` - для превью).

**Состояния**
- Ошибки полей: после ухода с поля или при отправке. Подчёркивание `siren` 2px и квадратная метка `siren`; сам текст ошибки - `ash`, потому что сирена на `void` не держит контраст мелкого текста. Фокус уходит на первое неверное поле.
- Отправка: кнопка «Передача…», поля заблокированы, бегущая полоса.
- Успех: «Сигнал принят» с кадрами помех и кнопкой «Передать ещё».
- Ошибка сети: плашка с рамкой `siren` и `role="alert"`, данные сохраняются.

**Валидация:** имя ≥ 2 символа; контакт - `@username` (4-32), ссылка `t.me/…` или email; сообщение ≥ 10 символов.
