# Monogram

Монограмма «AA» шрифтом `monogram` (UnifrakturCook 700) - единственный логотип: хедер, фавикон, водяной знак на превью, печать на карточках и бирках.

**Props:** `variant` - `mark` (логотип, текст для скринридера «Артем Артемов»), `seal` (круглая печать с двойной рамкой, повёрнута на −9°, декоративная), `watermark` (крупный полупрозрачный знак, декоративный); `text` - по умолчанию `AA`; `label` - подпись для `mark`.

- Цвет наследуется (`currentColor`): в Мире 1 - `ink` или `stain`, в Мире 2 - `ash`, на бирках - `rust`.
- Блэклеттером набираются только буквы «AA». Полное имя - `display-xl` (Unbounded): у UnifrakturCook нет кириллицы.
- Не рисуйте монограмму картинкой: это текст, он масштабируется и красится токенами.
