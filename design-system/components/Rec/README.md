# Rec

Мигающий индикатор «● REC»: точка `siren` со свечением и метка `label`. Справа в хедере, в дисплее формы («ON AIR» / «TX») и на постере при наведении («PLAY»).

**Props:** `label` (по умолчанию `REC`), `className`.

- Мигание `steps(2)` с периодом `blink`; при `prefers-reduced-motion` точка горит ровно.
- Точка - одно из трёх законных мест сирены. Больше ничего красным рядом не ставьте.
