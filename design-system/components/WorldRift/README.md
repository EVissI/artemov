# WorldRift

Переход между мирами, привязанный к прокрутке, но без залипания: секция высотой 140vh едет вместе со страницей, а эффект проигрывается, пока она проходит через экран (от входа снизу до середины ухода вверх). Скролл ничем не блокируется. Обои рвутся вертикальными полосами с рваными краями, куски отслаиваются и падают, под ними проступают решётка, рифлёный лист и перфорация. Палитра уходит в Мир 2, туман темнеет, около 56% вспыхивает сирена и радиопомехи, надпись «ДАЛЬШЕ - РАБОТЫ» меняет `seam` на `ash`.

**Props:** `rift` (`content.rift`: `title` - две строки, `topMeta`, `bottomMeta`), `progress` (0…1 - ручное управление; без него прогресс считается по положению секции в окне), `strips` (число полос; по умолчанию 9, в лёгком режиме 6).

**Фазы прогресса**
- 0.03-0.40 - разрывы: края полос расходятся, появляются тёмные прорези.
- 0.30-0.94 - отслоение: полосы в случайном порядке заваливаются вниз с поворотом и тенью.
- 0.49-0.63 - сирена (кольцевая вспышка по краям, не заливка) и красная линия.
- 0.42-0.70 - помехи: canvas-шум, перерисовывается только пока уровень > 0.

- При `prefers-reduced-motion` секция становится статичной высотой в экран и сразу показывает финал (металл и надпись), без вспышек и шума.
- Производительность: на скролле меняются только `transform` и `opacity` (рваные края считаются один раз), помехи рисуются на маленьком canvas через кадр и только пока секция на экране.
- Звук не играет никогда.
- Узор обоев непрерывен через все полосы: внутренний слой каждой полосы - ширина всей сцены со сдвигом.
