# Landing

Весь одностраничный лендинг Артема Артемова, собранный из одного объекта контента (`content/content.json`). Порядок секций фиксирован: Header → Hero (Мир 1, туман) → About → Services → WorldRift → Works → Cases → Contact → Footer, поверх - `Atmosphere`.

**Что передаёт потребитель**
- `content` - объект по схеме `content/content.json` (обязателен). Страница ничего не хардкодит: тексты, услуги, цифры, работы, кейсы и контакты берутся только отсюда.
- `onSubmitLead(values)` - функция, возвращающая Promise; по умолчанию `AA.api.submitLead` (имитация). Отказ промиса показывает состояние ошибки формы.
- `contained` - `true`, когда лендинг живёт в собственном контейнере прокрутки (превью, iframe админки). На сайте не нужен.
- `atmosphere` - `false`, чтобы выключить зерно, сканлайны и виньетку.
- Режим правки: оберните `Landing` в `AA.EditContext.Provider` с объектом редактора (так делает админка, `src/admin.jsx`). Тогда тексты правятся на месте, слоты медиа подсвечены, видны черновики работ. Новый текст в компоненте выводите через `<E p="путь.в.контенте" v={значение} />` - без провайдера это просто строка.

**Правила**
- Каждая секция несёт `data-theme="fog"` или `data-theme="other"`: так переключаются семантические токены `surface`, `ink`, `ink-muted`, `line-strong`, `focus`. Новые секции подключайте так же.
- Хедер сам берёт тему секции под собой (`data-header`) и подсвечивает пункт меню текущего раздела.
- Работы с `published: false` не показываются; порядок - по `order`.
- Для бэкенда: `AA.api.loadContent({ endpoint })` читает JSON с сервера и падает обратно на `window.AA_CONTENT`; `AA.api.submitLead(payload, { endpoint })` шлёт POST. Имя со словом «ошибка» в режиме имитации даёт отказ - для проверки состояния.

**Нельзя**
- Включать звук автоматически.
- Заливать крупные площади `siren`.
